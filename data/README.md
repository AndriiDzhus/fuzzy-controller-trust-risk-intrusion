# Навчальні дані контролерів

Апка працює з **одним файлом на контролер**, у кожному лише чотири колонки:
три входи контролера і еталонна відповідь.

| Файл | Контролер, метод | Рядків | Колонки |
|---|---|---|---|
| `security.csv` | Безпека, ANFIS | 200 | `EC, TP, Lat, SR` |
| `intrusion.csv` | Вторгнення, ГА | 500 | `NP, Rate, We, IP` |

Саме ці файли віддає кнопка «Отримати .xlsx» у блоці «Навчання моделі» (весь файл
або перші N рядків), і на них працює кнопка «Навчити на датасеті за замовчуванням».
Поділ на навчальну / валідаційну / тестову вибірки (70/30 для Безпеки, 70/15/15
для Вторгнень) апка робить сама, детерміновано (seed 42).

## Як побудовано файли

Файли створює `scripts/data/make-app-datasets.js` (`npm run data:app`), детерміновано:

- **входи** розподілено рівномірно по робочих діапазонах контролерів:
  EC 0,01–0,05 кВт·год/ГБ, TP 10–35 дБм, Lat 1–10 мс; NP 0–15, Rate 0–3000 пак/с
  (рівномірно в логарифмічній шкалі, щоб три порядки термів 15 / 150 / 1500 пак/с
  були представлені однаково), We 0–250;
- **ціль** дає «експерт датасету» — експертний контролер, у якого кілька
  параметрів зсунуто (Безпека: синглтони «дуже малий» 20 → 26, «середній»
  60 → 54, «великий» 80 → 86, вершина «середнього» EC 0,025 → 0,032, край
  «малої» TP 20 → 16, край «малої» Lat 5 → 4, початок «великої» Lat 5 → 6,5;
  Вторгнення: центри вихідних термів «відсутня» 0 → 3,5 і «мала» 30 → 28, центр «малого»
  NP 3 → 3,45, центр «великого» We 245 → 238 — зсуви помітні на графіках «до / після»),
  плюс шум вимірювання (σ = 0,22 для SR, 0,0175 для IP). SR записано з
  точністю 0,1, IP — 0,0001.

Тому експертна модель помітно відрізняється від даних, навчання має що
відновити (і зміни функцій належності добре видно у «Що змінилося»), а крива
похибки падає до рівня шуму, як у MATLAB-експериментах дисертації.

| Контролер | Експертна модель | Після навчання | MATLAB (дисертація) |
|---|---|---|---|
| Безпека (ANFIS, 100 епох) | RMSE ≈ 7,5 | 0,361 (train) / 0,367 (test) | 0,361 |
| Вторгнення (ГА, 150 поколінь) | ≈ 0,83 | 0,058 (train) / 0,070 (test) | 0,0297 → 0,0186 |

Крива ANFIS: 7,5 → 6,5 (епоха 1, МНК) → 4,0 (3) → 1,6 (5) → 0,7 (8) → 0,6 (20) →
0,39 (50) → 0,36 (100). Крива ГА: найкраща RMSE 0,83 «полицею» до ~6-го покоління, далі
сходинки (0,32 на 20-му, 0,17 на 30-му, 0,10 на 50-му) і плавне уточнення (0,083 на 100-му,
0,058 на 150-му); «середнє» по всіх нащадках покоління до відбору, як у MATLAB,
падає з ≈ 22 до ≈ 2 за ~10 поколінь і далі «шумить» біля 1–1,5 (нащадки зі зміненим
правилом дають великі викиди).
Повертається хромосома покоління з найменшою валідаційною похибкою (захист від
перенавчання).

Колонки у файлах:

| Колонка | Зміст | Діапазон |
|---|---|---|
| `EC` | Energy Consumption, споживана енергія, кВт·год/ГБ | 0–0,05 |
| `TP` | Transmit Power, потужність передачі, дБм | 0–40 |
| `Lat` | Latency, затримка, мс | 0–10 |
| `SR` | індекс ризику безпеки (ціль ANFIS) | 0–100 |
| `NP` | Number, кількість пакетів | 0–15 |
| `Rate` | швидкість передавання, пакетів/с | 0–3000 |
| `We` | Weight, вага / навантаження | 0–250 |
| `IP` | вірогідність вторгнення (ціль ГА) | 0–100 |

Орієнтири для експертних значень: SR — синглтони виходу 0 / 20 / 40 / 60 / 80 / 100
(немає … дуже великий); IP — центри термів 0 «відсутня», 30 «мала», 60 «середня»,
100 «велика». Проміжні значення допустимі.

## Сценарій для викладача

1. Отримати `.xlsx`, відкрити в Excel.
2. Змінити цільову колонку (`SR` або `IP`), дописати чи прибрати рядки
   (мінімум 10 навчальних).
3. Завантажити файл назад — навчання стартує одразу; порівняти з експертною
   моделлю і застосувати.

Для Безпеки всі вхідні точки файла є ще й точками **покриття**: навчені
трикутники не можуть лишити жодну з них без спрацьованого правила.

Скрипти `npm run train:security` і `npm run train:intrusion` навчають на тих самих
файлах (`--data <csv>` — на іншому) і записують результат у
`src/controllers/trained/*.json`.
